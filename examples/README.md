# Examples

Use this folder for your own public examples.

A good example set contains:

1. source image;
2. standalone stamp output;
3. full poster output;
4. one failure comparison showing why an inexact regenerated crop is wrong.

For a public GitHub repository, prefer:

- your own photography;
- AI-generated demo photography;
- public-domain / CC0 imagery with clear reuse rights.

Avoid committing third-party reference photography unless you have redistribution permission.
